# PrimeFlow

Prototype de dashboard métier pour le secteur CEE (Certificats d’Économies d’Énergie).

## Objectif
Digitaliser et simplifier le suivi des dossiers CEE :
- suivi des chantiers
- contrôle documentaire
- facturation
- visibilité temps réel

## Stack
- Python
- Streamlit
- Pandas
- Plotly

## Statut
Prototype en cours de développement (freelance demo project)
